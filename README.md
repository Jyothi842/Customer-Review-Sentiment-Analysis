# Customer Review Sentiment Analysis

## Project Overview
Customer Review Sentiment Analysis is a machine learning project that analyzes customer feedback and classifies reviews into three categories: Positive, Negative, and Neutral.

## Objectives
- Analyze customer review text using Natural Language Processing (NLP).
- Predict the sentiment of individual customer reviews.
- Analyze multiple reviews from a CSV file.
- Visualize sentiment distribution using charts.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- TF-IDF
- Logistic Regression
- Streamlit
- Matplotlib

## Features
- Single-review sentiment prediction
- Bulk review analysis through CSV upload
- Sentiment distribution chart
- Download analyzed results

## Installation

1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install dependencies:

   `pip install -r requirements.txt`

4. Train the model:

   `python train_model.py`

5. Launch the application:

   `python -m streamlit run app.py`

## Dataset
The project uses labelled customer reviews for sentiment classification. See the original dataset source and licence before redistributing the data.
